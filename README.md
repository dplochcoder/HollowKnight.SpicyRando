# HollowKnight.SpicyRando

A collection of questionable combat-focused modifications to Hallownest. Enable in mod options to add spicy features to vanilla (non-rando) saves.

## Rando Integration

Spicy Rando features can be enabled in rando. Some of them alter logic to account for increased combat difficulty.

Spicy Rando is integrated with Rando Settings Manager for easy sharing of settings as well.

## CSR Integration

Spicy Rando integrates with ConnectionSettingsRando and can be enabled randomly on a per-feature basis.

Individual features can be filtered from CSR via the path `SpicyRando.Features.#FEATURE_NAME#`.

## Features

### The Hoarder

Enabling this feature slightly expands the strength and variety of the Collector's minions.

Alters logic requirements for the Collector fight.

### Spicy Bretta

Enabling this feature makes rescuing Bretta slightly more difficult after obtaining Mantis Claw.

Does not alter logic.

### Super Myla

Enabling this feature makes it slightly more difficult to kill Myla after obtaining Crystal Heart.

Does not alter logic.

### Git Gud

Enabling this feature makes obtaining Mothwing Cloak slightly more difficult.

Alters logic requirements for the Hornet 1 fight.

### Nightmare Warriors

Every dream warrior has a 'nightmare' setting for a harder, longer fight, with more HP and advanced attacks.
